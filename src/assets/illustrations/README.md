# Illustrations

Représentations graphiques détaillées (à distinguer des icônes symboliques).

- **stars/** — Étoiles par type spectral (O, B, A… M, L, T, Y, D, pulsar)  
  Utilisé par `components/illustrations/StarSvgInline.vue` (vue Système)
- **planets/** — Planètes par composition (terrestre, géante gazeuse, etc.)  
  Utilisé par `components/illustrations/PlanetSvgInline.vue` (vue Système)
