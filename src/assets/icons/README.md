# Icônes

Icônes symboliques pour types d’objets, signaux, instruments.

- **observation-types/** — Types d’observation (système, exoplanète, échantillon)  
  `icon-systeme.svg` (étoile) · `icon-exoplanete.svg` (planètes, astres) · `icon-echantillon.svg` (OBJET)  
  Utilisé par `ObservationTypeIcon.vue`
- **signal-types/** — Structure des signaux (sursaut, pulse, non-uniforme, carré)  
  Utilisé par `SignalTypeIcon.vue`
